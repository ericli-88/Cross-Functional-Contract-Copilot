# 财务审核清单（乙方视角）

目标：确保收款有保障、账期可接受、资金占用和坏账风险可控。

重点检查：

1. 付款节点
   - 是否有预付款或首付款，建议签约后即支付一定比例。
   - 阶段款是否绑定客观里程碑，而不是客户主观满意。
   - 尾款是否避免长期拖延。

2. 付款周期
   - 账期是否过长，建议一般不超过 30 天。
   - 是否从“收到合格发票”起算，还是从验收/账单确认起算。
   - 是否存在客户内部流程完成后才付款等不可控条件。

3. 验收与付款解耦
   - 是否约定客户逾期不验收视为验收通过。
   - 是否避免“客户满意后付款”“最终用户确认后付款”等主观条件。
   - 是否限制客户以轻微问题拒付全部款项。

4. 发票与税费
   - 合同金额是否含税，税率和发票类型是否明确。
   - 开票是否不等于放弃收款权。
   - 税费、银行手续费、跨境支付费用由谁承担是否明确。

5. 逾期付款保护
   - 客户逾期付款是否有违约金或利息。
   - 逾期达到一定天数时，我方是否可暂停服务且不承担违约责任。
   - 是否保留追索律师费、诉讼费、保全费等合理费用的权利。

6. 质保金和扣款
   - 质保金比例是否过高，建议不超过 5%-10%。
   - 质保金释放期限是否明确。
   - 客户是否有单方扣款、抵扣、罚款权利。

高风险判断：

- 无预付款、长账期、验收主观、客户可单方扣款、发票绑定付款过重、逾期无保护、终止不结算已完成工作。
