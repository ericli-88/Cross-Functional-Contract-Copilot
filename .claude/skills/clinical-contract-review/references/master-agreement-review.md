# 框架合作协议审核要点（乙方视角—保护服务提供方）

适用于：年度客户框架、长期运维框架、常态化战略合作等长期合作总规则协议。

定位：无单笔具体金额、无具体交付成果，仅约定通用合作权责、结算规则、合作边界，后续通过SOW/单项合同/订单执行。

作为乙方签署框架协议，核心保护目标：保护最低价格、限制客户单方变更、确保后续订单定价权、保护我方背景IP。

---

## 一、业务Leader审核Skills（乙方视角）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 合作边界 | 长期合作范围是否在我方能力范围内？是否包含了我方不擅长的业务？ | 🟡 | 框架范围过宽导致被迫承接不擅长业务 |
| 分包限制 | 是否禁止我方合理分包？是否允许我方将非核心工作分包？ | 🔴 | 完全禁止分包，增加成本 |
| 订单生效规则 | 后续SOW、单项合同、订单的生效规则是否保护我方？是否需双方确认？ | 🟡 | 客户单方下单，我方被动接受 |
| 有效期与续约 | 合作有效期是否有利于我方？续约是否需双方协商？是否有自动续期？ | 🟡 | 自动续期导致长期绑定不利条款 |
| 合作排他性 | 是否要求我方排他合作？排他范围是否合理？是否给予补偿？ | 🟡 | 过度排他限制我方业务 |
| 业务优先级 | 框架内项目的优先级分配机制是否明确？客户是否可随意要求优先？ | ⚪ | 资源分配争议 |
| 最低采购量 | 客户是否有最低采购量承诺？未达标是否补偿？ | 🟡 | 客户承诺采购量却未执行 |
| 客户变更权 | 客户是否可单方变更框架条款？ | 🔴 | 客户单方变更框架条款 |

## 二、法务审核Skills（乙方视角）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 权责对等 | 通用违约责任、争议解决、知识产权归属、数据所有权条款是否对等？ | 🔴 | 框架条款不对等，后续所有订单受影响 |
| GCP合规兜底 | 客户是否作为申办方承担GCP合规？我方仅作为服务商配合？ | 🔴 | 框架要求我方承担申办方责任 |
| 知识产权 | 框架内我方背景IP是否保留所有权？前景IP是否共享？ | 🟡 | 后续订单产生成果归属争议 |
| 终止善后 | 协议终止后客户是否支付已完成工作费用？ | 🟡 | 终止后客户不支付费用 |
| 数据安全 | 数据保护责任是否由客户（控制者）承担？我方仅按指令处理？ | 🔴 | 框架要求我方承担控制者责任 |
| 保密升级 | 框架保密条款是否过高？是否应区分等级？ | 🟡 | 保密力度过度 |
| 框架与订单冲突 | 订单与框架条款冲突时以何为准？是否应有利于我方？ | 🔴 | 框架条款被订单覆盖，失去保护 |
| 适用法律 | 适用法律、争议解决机制是否有利于我方？ | 🟡 | 管辖地不利 |
| 责任限制 | 框架是否设置了我方责任上限？ | 🔴 | 框架无责任上限 |
| 排他限制 | 排他条款是否限制我方与其他客户合作？ | 🟡 | 过度排他限制业务 |

## 三、财务审核Skills（乙方视角）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 通用计价规则 | 框架内通用计价规则（FTE单价、系统许可基准价）是否保护最低价格？ | 🟡 | 客户要求低于成本价 |
| 调价机制 | 年度调价机制是否有涨幅下限保护？是否可随成本上涨调整？ | 🟡 | 无价格保护 |
| 结算通用规则 | 结算周期、付款时限是否≤30天？ | ⚪ | 结算周期过长 |
| 预付款限制 | 框架是否允许预付款？是否争取框架签署时即收取预付款？ | 🟡 | 无预付款，资金压力大 |
| 费用封顶 | 年度/总费用是否由客户承诺最低采购量？ | 🟡 | 客户承诺采购量却未执行 |
| 订单定价权 | 后续订单定价权是否由双方协商？客户是否可单方面压价？ | 🟡 | 客户单方面压价 |
| 最低采购量 | 客户是否有最低采购量承诺？未达标是否有补偿？ | 🟡 | 客户无最低采购量 |

> **财务不审核**：单笔订单金额、具体付款节点、验收条件（这些在后续订单中审核）。但应审核框架是否保护我方最低利益。

## 四、框架协议快速审核 Checklist（乙方视角）

### 业务Leader必查
- [ ] 合作范围在我方能力范围内，不含不擅长业务
- [ ] 允许合理分包非核心工作
- [ ] 订单需双方确认，非客户单方生效
- [ ] 无自动续期，或需双方确认续期
- [ ] 无过度排他限制，或排他给予补偿
- [ ] 客户有最低采购量承诺
- [ ] 客户不可单方变更框架条款

### 法务必查
- [ ] 权责对等，无霸王条款
- [ ] 客户作为申办方承担GCP合规
- [ ] 我方背景IP保留所有权
- [ ] 数据安全责任由客户（控制者）承担
- [ ] 我方责任上限明确（≤框架年度金额）
- [ ] 框架与订单冲突时以有利于我方为准
- [ ] 管辖地对我方有利或中性
- [ ] 通用审核底线（5条）全部满足

### 财务必查
- [ ] 通用计价规则保护最低价格
- [ ] 年度调价有涨幅下限保护
- [ ] 结算周期≤30天
- [ ] 客户有最低采购量承诺
- [ ] 订单定价权由双方协商
- [ ] 无客户单方面压价权
