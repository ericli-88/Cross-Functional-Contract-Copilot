# 业务类兼职协议审核要点

适用于：公司业务推广先锋官、兼职运营、业务辅助兼职等岗位。

特点：紧密绑定公司业务线索、成交激励、业务权限、商务规则，必须业务部门前置审核。

审核链路：起草人 → 业务Leader（业务条款审核） → 人事（用工合规） → 法务（法律终审）。不经过财务。

---

## 一、业务Leader审核Skills（专属，独有审核权）

| 检查项 | 审核要点 | 风险等级 | 常见风险 |
|--------|---------|---------|---------|
| 工作内容 | 兼职业务工作内容、对外推广权限、业务边界是否准确？ | 🔴 | 权限过大导致业务失控 |
| 激励体系 | 线索奖励、成交提成、阶梯分成、结算规则是否准确无歧义？ | 🔴 | 激励规则模糊导致纠纷 |
| 客户线索归属 | 客户线索归属、业务资料使用、对外口径约束是否清晰？ | 🔴 | 客户资源归属争议 |
| 结算条件 | 业务绩效结算条件、不予结算场景是否完整覆盖？ | 🟡 | 结算条件遗漏 |
| 业务保密 | 业务保密、客户资源保护条款是否到位？ | 🔴 | 兼职人员带走客户资源 |
| 业务边界 | 兼职是否涉及公司核心业务竞争？是否有竞业限制？ | 🟡 | 兼职人员同时为竞争对手工作 |
| 权限回收 | 兼职终止时业务权限、系统账号、客户资料的回收机制？ | 🟡 | 权限未及时回收 |
| 品牌使用 | 是否允许使用公司品牌对外推广？使用范围和限制？ | 🟡 | 品牌滥用导致声誉风险 |
| 合规红线 | 兼职推广是否涉及虚假宣传、医疗广告违规？ | 🔴 | 推广违规导致行政处罚 |
| 业务目标 | 兼职的业务目标、KPI、考核周期是否明确？ | 🟡 | 目标不明导致激励争议 |
| 独家合作 | 是否要求兼职人员独家为公司工作？ | ⚪ | 独家要求影响兼职积极性 |
| 业务培训 | 公司是否提供业务培训？培训费用是否承担？ | ⚪ | 培训费用争议 |

## 二、人事审核Skills（用工合规）

| 检查项 | 审核要点 | 风险等级 | 常见风险 |
|--------|---------|---------|---------|
| 劳务属性 | 是否明确为劳务关系而非劳动关系？条款是否彻底隔离劳动关系风险？ | 🔴 | 被认定为劳动关系，承担社保、经济补偿等责任 |
| 服务周期 | 兼职服务周期、工作频率、工作时长是否明确？ | 🟡 | 服务周期不明 |
| 工作交付 | 兼职工作的交付标准、验收方式是否明确？ | 🟡 | 交付标准不明 |
| 终止退出 | 兼职终止条件、通知期、退出流程是否清晰？ | 🟡 | 终止流程不清 |
| 交接流程 | 兼职终止时的工作交接、资料移交、客户信息移交流程？ | 🟡 | 交接不清导致客户流失 |
| 考勤管理 | 兼职是否适用考勤？如何记录工作时间？ | ⚪ | 考勤管理争议 |
| 商业保险 | 是否为兼职人员购买商业意外险？保额是否充足？ | 🟡 | 意外无保障 |
| 不适用条款 | 是否明确不适用带薪年假、加班费、经济补偿等劳动权利？ | 🔴 | 未明确隔离导致劳动关系认定 |
| 年龄限制 | 兼职人员是否年满16周岁？是否超过退休年龄？ | 🔴 | 用工年龄违法 |
| 多重兼职 | 是否允许兼职人员同时为其他公司提供类似服务？ | ⚪ | 多重兼职影响工作质量 |
| 身份核验 | 兼职人员身份信息、联系方式、紧急联系人是否核验？ | 🟡 | 身份不明导致管理困难 |

## 三、法务审核Skills（法律终审）

| 检查项 | 审核要点 | 风险等级 | 常见风险 |
|--------|---------|---------|---------|
| 劳动关系隔离 | 是否明确劳务关系？工作内容、管理方式、报酬支付方式是否体现劳务关系特征？ | 🔴 | 被认定为劳动关系 |
| 权责对等 | 是否无不合理绑定、无限追责条款？违约责任是否双向？ | 🔴 | 权责不对等 |
| 保密条款 | 保密义务范围、期限、泄密责任是否明确？ | 🟡 | 保密条款不足 |
| 知识产权 | 兼职期间产生的业务成果（客户线索、推广材料）归属？ | 🟡 | 成果归属争议 |
| 违约条款 | 违约条款是否双向？是否合理？违约金是否过高？ | 🟡 | 违约金不合理 |
| 解约条款 | 解约条件、通知期、结算规则是否清晰？ | 🟡 | 解约不清 |
| 争议解决 | 争议解决方式、管辖地、适用法律是否明确？ | ⚪ | 争议解决不明 |
| 税务合规 | 劳务报酬的税务处理（预扣预缴、发票）是否合规？ | 🟡 | 税务不合规 |
| 社会保险 | 是否明确不缴纳社保（劳务关系）？是否建议购买商业保险？ | 🔴 | 未明确隔离社保义务 |
| 结算争议 | 结算条件、不予结算场景、结算周期、支付方式是否明确？ | 🟡 | 结算争议 |
| 品牌使用 | 是否允许使用公司品牌？使用范围、限制、终止后是否停止使用？ | 🟡 | 品牌使用失控 |
| 合规红线 | 是否约定推广合规要求（禁止虚假宣传、医疗广告）？违规责任归属？ | 🔴 | 违规推广导致公司责任 |
| 数据保护 | 兼职人员接触的客户信息、业务数据的使用限制？ | 🔴 | 数据泄露 |
| 反商业贿赂 | 是否约定反商业贿赂条款？ | 🟡 | 兼职人员贿赂风险 |
| 连带责任 | 兼职人员过错是否导致公司承担连带责任？如何隔离？ | 🔴 | 连带责任无法隔离 |

## 四、业务兼职协议 vs 全职劳动合同 关键区别（审核人注意）

| 维度 | 业务兼职协议 | 全职劳动合同 |
|------|------------|------------|
| 法律关系 | 劳务关系（民事合同） | 劳动关系（受劳动法保护） |
| 审核链路 | 业务Leader→人事→法务 | 人事→法务 |
| 社保义务 | 无（建议购买商业意外险） | 必须缴纳（法定义务） |
| 经济补偿 | 无 | 法定解除时须支付 |
| 加班工资 | 无 | 有法定的加班工资倍数 |
| 带薪年假 | 无 | 有法定带薪年假 |
| 最低工资标准 | 不适用 | 必须≥当地最低工资 |
| 违约金 | 可约定（需合理） | 严格限制 |
| 解除条件 | 可约定 | 法定解除条件 |
| 争议解决 | 仲裁或诉讼 | 劳动仲裁前置 |
| 税务处理 | 劳务报酬（20%预扣） | 工资薪金（累计预扣） |
| 竞业限制 | 可约定（需合理） | 法定限制（≤2年+补偿） |
| 业务审核 | 必须有（业务Leader专属） | 无 |
| 核心风险 | 被认定为劳动关系 | 违反劳动法强制性规定 |

## 五、劳动关系隔离 checklist（法务/人事必查）

兼职协议必须满足以下特征，否则极可能被认定为劳动关系：

- [ ] 工作方式：自主安排工作时间和工作方式，不受公司考勤管理
- [ ] 管理关系：不接受公司日常管理、绩效考核、岗位调动
- [ ] 报酬方式：按工作成果/项目结算，而非固定月薪
- [ ] 工具设备：自行提供工作工具和设备，非公司配发
- [ ] 工作场所：不固定在公司办公场所，可远程/自主安排
- [ ] 业务独立性：可同时为其他公司/客户提供服务
- [ ] 合同性质：明确约定为"劳务合同"或"业务合作协议"，非"劳动合同"
- [ ] 社保声明：明确约定不缴纳社保，由兼职人员自行负责
- [ ] 劳动权利排除：明确约定不适用带薪年假、加班费、经济补偿等劳动权利

**如以上特征不满足3项以上，触发🔴否决级，必须修改条款或改为劳动合同。**
