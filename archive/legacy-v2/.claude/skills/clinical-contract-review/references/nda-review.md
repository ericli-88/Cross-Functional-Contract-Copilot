# 保密协议（NDA）审核要点（乙方视角—保护我方信息）

适用于：合作前置沟通、尽调、专家合作、资料交换、涉密对接等场景。

审核链路：起草人 → 法务终审。不经过业务Leader、不经过人事、不经过财务。

作为服务提供方签署NDA，核心保护目标：限制我方保密义务、保护我方技术/商业信息、确保客户信息可被合理使用。

---

## 一、法务审核Skills（唯一审核主体）

### 1.1 保密信息界定（保护乙方）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 我方保密信息 | 是否明确约定客户也需对我方信息保密？是否清单化我方保密信息？ | 🔴 | 仅约束我方保密，客户不保密 |
| 临研涉密范围 | 客户是否要求我方对其全部信息保密？范围是否过宽？ | 🔴 | 客户要求对我方全部信息保密，范围过宽 |
| 最高等级涉密 | 客户核心数据是否被过度列为最高等级？是否导致我方无法正常使用？ | 🔴 | 过度分级导致我方无法使用必要信息 |
| 保密信息清单 | 是否提供保密信息清单？或约定"以标注为准"？ | 🟡 | 范围模糊，客户事后扩大范围 |
| 口头信息 | 口头披露的保密信息是否要求在披露后由客户书面确认？ | 🟡 | 客户口头声称某信息为保密 |
| 反向工程 | 是否允许我方通过合法手段获得的信息不受保密约束？ | ⚪ | 合法获得信息仍被约束 |
| 通用知识排除 | 是否明确排除我方已有知识、通用知识、公开信息？ | 🔴 | 我方通用知识被纳入保密范围 |

### 1.2 保密期限（保护乙方）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 期限合理性 | 保密期限是否过长？普通信息是否可缩短至3年？ | 🟡 | 保密期限过长，限制我方长期发展 |
| 临研数据期限 | 客户要求临研数据保密期限是否过长？是否可区分等级？ | 🟡 | 全部信息永久保密 |
| 商业信息期限 | 我方商业信息保密期限是否合理？ | ⚪ | 商业信息保密期限争议 |
| 期限起算 | 保密期限起算点是否明确？是否从披露日起算而非协议终止日？ | 🟡 | 起算点不明导致期限延长 |
| 永久保密 | 是否约定特定信息永久保密？是否仅限于核心商业秘密？ | ⚪ | 永久保密范围过宽 |

### 1.3 双方保密义务对等（保护乙方）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 义务对等 | 双方保密义务是否对等？客户是否也承担同等保密义务？ | 🔴 | 仅约束我方 |
| 使用限制 | 双方对保密信息的使用限制是否一致？我方使用客户信息是否受限？ | 🟡 | 客户信息使用受限 |
| 披露限制 | 双方向第三方披露的条件是否一致？ | ⚪ | 披露条件不对等 |
| 员工约束 | 双方对各自员工的保密约束是否一致？ | ⚪ | 员工约束不对等 |
| 第三方披露 | 双方向第三方披露的条件是否一致？ | ⚪ | 第三方披露条件不对等 |

### 1.4 泄密违约责任（保护乙方）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 违约责任明确 | 客户泄密违约责任是否明确？是否与我方对等？ | 🔴 | 客户违约责任低于我方 |
| 赔偿计算 | 赔偿计算方式是否对等？我方赔偿上限是否过高？ | 🟡 | 赔偿计算不对等 |
| 稽查衍生风险 | 泄密导致的稽查衍生风险责任是否由泄密方承担？ | 🔴 | 我方泄密承担衍生风险，客户泄密不承担 |
| 惩罚性赔偿 | 是否包含惩罚性赔偿？是否应删除或双向？ | ⚪ | 仅约束我方惩罚性赔偿 |
| 举证责任 | 泄密举证责任是否分配合理？ | ⚪ | 举证责任过重 |
| 责任上限 | 我方泄密责任上限是否过高？ | 🟡 | 责任上限过高 |

### 1.5 除外条款与免责（保护乙方）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 公开信息除外 | 公开信息除外是否合理？ | ⚪ | 除外合理 |
| 自有信息除外 | 我方已有信息是否被排除在保密范围外？ | 🔴 | 我方已有信息被纳入保密 |
| 独立开发除外 | 我方独立开发的信息是否被排除？ | 🔴 | 独立开发信息被纳入保密 |
| 强制披露除外 | 法律强制披露除外是否要求事先通知？ | 🟡 | 强制披露无通知 |
| 政府披露除外 | 政府、监管机构披露除外是否要求事先通知？ | 🟡 | 政府披露无通知 |
| 对方过度免责 | 客户免责条款是否过度宽泛？ | 🔴 | 客户过度免责 |
| 除外证明 | 除外信息是否要求提供证明？ | ⚪ | 除外无证明 |

### 1.6 其他关键条款（保护乙方）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 返还/销毁 | 保密协议终止后保密信息的返还或销毁义务？是否双方均需返还？ | 🟡 | 仅要求我方返还 |
| 留存例外 | 法律法规要求留存的信息除外？ | ⚪ | 留存例外合理 |
| 保密标识 | 是否要求保密信息标注保密标识？ | ⚪ | 无标识要求 |
| 无保密义务确认 | 是否约定未标注保密标识的信息不受保密约束？ | 🔴 | 未标注即不受约束导致范围失控 |
| 期限届满后 | 保密期限届满后是否仍对未公开信息承担保密义务？ | 🟡 | 期限届满后无保密义务 |
| 适用法律 | 适用法律、管辖地是否对我方有利？ | ⚪ | 管辖地不利 |
| 争议解决 | 争议解决方式（仲裁/诉讼）？ | ⚪ | 争议解决方式不明 |
| 协议期限 | 保密协议期限（如1年）与保密期限（如5年）是否区分？ | 🟡 | 协议期限与保密期限混淆 |
| 双方签署 | 是否为双向NDA（双方互负保密义务）？ | 🔴 | 单向NDA仅约束我方 |
| 争议通知 | 争议发生时的通知义务？ | ⚪ | 争议通知义务缺失 |
| 不限制合作 | 是否明确NDA不限制双方与其他方合作？ | 🟡 | NDA隐含排他限制 |
| 知识产权归属 | 是否明确NDA不涉及知识产权转让？ | 🔴 | NDA被隐含知识产权转让 |

## 二、NDA 快速审核 Checklist（法务专用—乙方视角）

- [ ] 双向NDA：双方互负保密义务，非单向
- [ ] 我方保密信息清单明确，客户也需对我方保密
- [ ] 保密范围不过宽，排除我方已有知识、通用知识、公开信息
- [ ] 保密期限合理，可区分普通信息（3年）和核心数据（5年）
- [ ] 我方泄密责任上限合理，与客户对等
- [ ] 客户泄密违约责任明确，与我方对等
- [ ] 除外条款合理，客户无过度免责
- [ ] 终止后双方均需返还/销毁保密信息
- [ ] 协议期限与保密期限区分清晰
- [ ] 适用法律、管辖地对我方有利或中性
- [ ] NDA不隐含排他限制、知识产权转让
- [ ] 独立开发信息被排除在保密范围外

以上任一项不满足，标注对应风险等级（🔴🟡），出具审核意见。
