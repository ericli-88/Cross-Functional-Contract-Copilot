# 全职劳动合同审核要点

适用于：公司正式全职员工入职签署的劳动合同。

审核链路：起草人（人事）→ 人事审核 → 法务终审。不经过业务Leader、不经过财务。

---

## 一、人事审核Skills

| 检查项 | 审核要点 | 风险等级 | 常见风险 |
|--------|---------|---------|---------|
| 薪资结构 | 基本工资、绩效工资、补贴、奖金结构是否合规？是否明确？ | 🔴 | 薪资结构不明导致劳动纠纷 |
| 发薪周期 | 发薪周期（月薪/半月薪）是否符合公司制度？是否明确发薪日？ | 🟡 | 发薪周期不明确 |
| 试用期规则 | 试用期期限是否符合法定上限（合同期≥3年：≤6个月；1-3年：≤2个月；<1年：≤1个月）？ | 🔴 | 试用期超期违法 |
| 试用期工资 | 试用期工资是否≥转正工资的80%且≥当地最低工资标准？ | 🔴 | 试用期工资过低违法 |
| 岗位职责 | 岗位职责描述是否清晰？是否与实际岗位匹配？ | 🟡 | 岗位职责模糊导致考核争议 |
| 考勤制度 | 考勤方式、工时制度（标准工时/综合工时/不定时）是否明确？ | 🟡 | 考勤制度不明 |
| 绩效考核 | 绩效考核标准、周期、结果应用是否明确？ | 🟡 | 绩效标准主观导致争议 |
| 离职交接 | 离职交接流程、交接期、工作交接清单是否明确？ | 🟡 | 离职交接不清 |
| 社保合规 | 社保缴纳基数、缴纳地、缴纳比例是否合规？ | 🔴 | 社保不合规导致行政处罚 |
| 公积金 | 住房公积金缴纳是否合规？ | 🟡 | 公积金缴纳不合规 |
| 工作地点 | 工作地点是否明确？是否包含出差/外派安排？ | ⚪ | 工作地点争议 |
| 合同期限 | 合同期限（固定/无固定/完成一定工作）是否明确？ | 🟡 | 合同期限不明 |
| 续签规则 | 合同续签条件、次数、无固定期限转化规则？ | 🟡 | 续签规则不明 |
| 培训约定 | 专项培训的服务期约定、违约金计算是否合理？ | 🟡 | 培训违约金过高 |
| 规章制度 | 员工手册、规章制度是否作为合同附件？员工是否签收？ | 🟡 | 规章制度未签收，无效 |

## 二、法务审核Skills

| 检查项 | 审核要点 | 风险等级 | 常见风险 |
|--------|---------|---------|---------|
| 劳动法合规 | 是否符合《劳动法》《劳动合同法》《社会保险法》全部强制性规定？ | 🔴 | 违反强制性规定导致条款无效 |
| 违规免责 | 是否存在工伤免责、加班免责、社保免责等无效条款？ | 🔴 | 免责条款无效且违法 |
| 竞业限制 | 竞业限制范围（地域、行业、时间）是否合理？期限≤2年？ | 🟡 | 竞业限制过度 |
| 竞业补偿 | 竞业限制补偿金是否约定？标准是否≥离职前12个月平均工资的30%？ | 🟡 | 未约定补偿导致竞业无效 |
| 保密条款 | 保密义务范围是否适度？是否包含过度扩大的"所有信息"？ | 🟡 | 保密范围过度 |
| 保密期限 | 保密期限是否合理？是否永久？ | ⚪ | 保密期限争议 |
| 解约条件 | 双方解除条件是否符合法定标准？经济补偿计算是否合规？ | 🟡 | 解约条件违法 |
| 经济补偿 | 经济补偿标准（N/N+1/2N）是否约定？是否符合法定标准？ | 🟡 | 补偿标准不足 |
| 违约金限制 | 除专项培训服务期和竞业限制外，是否违法约定员工违约金？ | 🔴 | 违法违约金无效 |
| 工时休假 | 标准工时/综合工时/不定时工作制的审批是否合规？年休假、法定假日安排？ | 🟡 | 工时制度违法 |
| 加班工资 | 加班工资计算基数、倍数（1.5/2/3）是否合规？ | 🔴 | 加班工资不足 |
| 最低工资标准 | 试用期/转正后工资是否≥当地最低工资标准？ | 🔴 | 低于最低工资违法 |
| 合同形式 | 是否书面签署？是否在入职1个月内签署？ | 🔴 | 未签书面合同导致双倍工资风险 |
| 通知送达 | 通知送达方式、地址、电子送达是否有效？ | ⚪ | 通知无效 |
| 争议解决 | 劳动争议仲裁前置、管辖地是否合规？ | ⚪ | 争议解决方式违法 |
| 规章制度效力 | 规章制度是否经过民主程序制定？是否公示？ | 🟡 | 规章制度无效 |
| 特殊保护 | 女职工、未成年工、工伤员工等特殊保护是否合规？ | 🔴 | 特殊保护缺失 |
| 集体合同 | 是否涉及集体合同？集体合同与个人合同的关系？ | ⚪ | 集体合同优先性 |

## 三、劳动合同与业务合同的关键区别（审核人注意）

| 维度 | 劳动合同 | 业务合同 |
|------|---------|---------|
| 审核链路 | 人事→法务（不经过业务、财务） | 业务Leader→法务→财务 |
| 核心法律 | 《劳动法》《劳动合同法》 | 《民法典》《合同法》 |
| 强制性规范 | 大量强制性规范（不得约定除外） | 意思自治为主 |
| 违约金 | 严格限制（仅培训服务期和竞业限制） | 可自由约定 |
| 解除权 | 法定解除条件，严格限制 | 可约定解除条件 |
| 争议解决 | 劳动仲裁前置（必须先仲裁） | 仲裁或诉讼均可 |
| 赔偿上限 | 法定标准（经济补偿金、赔偿金） | 可约定 |
| 兜底条款 | 较少（以法定为准） | 需要详细约定 |
| 终止善后 | 工作交接、离职证明、社保转移 | 数据移交、资料交接、结算收尾 |
