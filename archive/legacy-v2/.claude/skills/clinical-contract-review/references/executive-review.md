# 总经理审核技能手册（乙方视角—管理层决策）

适用于需要总经理或管理层最终判断的合同审批节点，尤其是重大金额、重大客户、重大资源投入、重大责任例外或前序审核节点无法自行放行的事项。

作为总经理/管理层审核，核心目标是：**在风险可控前提下判断合同是否符合公司战略、利润目标、资源能力和授权边界。**

---

## 一、总经理审核重点

### 1.1 商业价值与战略匹配

| 检查项       | 审核要点                                                               | 风险等级 | 常见风险                             |
| ------------ | ---------------------------------------------------------------------- | -------- | ------------------------------------ |
| 客户战略价值 | 客户是否属于重点客户、标杆客户或长期合作对象？合同让步是否有明确回报？ | 🟡       | 为短期订单过度让步，无法形成长期价值 |
| 收入与利润   | 合同金额、毛利率、回款节奏是否符合公司经营目标？是否低于最低利润要求？ | 🔴       | 低毛利或亏损项目占用核心资源         |
| 机会成本     | 项目资源投入是否挤占更高价值项目？是否有明确优先级判断？               | 🟡       | 资源错配导致高价值项目延期           |
| 复购潜力     | 是否有后续订单、框架扩展或交叉销售机会？是否已落入合同或商务纪要？     | ⚪       | 预期收益未书面化，后续无法兑现       |

### 1.2 重大风险与例外授权

| 检查项       | 审核要点                                                             | 风险等级 | 常见风险                     |
| ------------ | -------------------------------------------------------------------- | -------- | ---------------------------- |
| 否决级风险   | 前序业务、法务、财务是否存在未关闭的🔴风险？是否必须先修订后再提交？ | 🔴       | 管理层在风险未量化时被动背书 |
| 赔偿上限例外 | 若客户坚持较高赔偿上限，是否有金额测算、保险覆盖或替代补偿条件？     | 🔴       | 单一项目风险超过公司承受能力 |
| 付款例外     | 若账期、预付款、质保金不达标，是否有客户信用证明和现金流评估？       | 🔴       | 回款风险被业务收入预期掩盖   |
| 终止例外     | 若客户保留单方终止权，是否确保已完成工作结算和取消费用保护？         | 🔴       | 客户终止导致沉没成本无法回收 |
| 资源例外     | 若交付周期或人力投入超出现有产能，是否明确额外资源、预算和负责人？   | 🟡       | 管理层批准后执行资源无法落地 |

### 1.3 跨部门结论一致性

| 检查项   | 审核要点                                               | 风险等级 | 常见风险                 |
| -------- | ------------------------------------------------------ | -------- | ------------------------ |
| 业务结论 | 业务是否确认范围、工期、验收和客户配合义务可执行？     | 🔴       | 管理层批准不可交付的承诺 |
| 法务结论 | 法务是否明确剩余法律风险、建议修改项和可接受底线？     | 🔴       | 法律风险未转化为决策事项 |
| 财务结论 | 财务是否确认收款节点、账期、毛利率和资金占用可接受？   | 🔴       | 合同签署后现金流压力失控 |
| 决策记录 | 对未采纳的修改建议，是否记录管理层接受理由和补偿措施？ | 🟡       | 后续争议无法追溯授权依据 |

### 1.4 最终放行条件

| 检查项     | 审核要点                                                           | 风险等级 |
| ---------- | ------------------------------------------------------------------ | -------- |
| 修改闭环   | 所有必须修改项是否已落实到合同正文、附件或补充说明？               | 🔴       |
| 授权边界   | 签署主体、金额、期限、责任上限是否在授权范围内？                   | 🔴       |
| 执行负责人 | 合同执行负责人、回款负责人、风险跟踪人是否明确？                   | 🟡       |
| 复审触发   | 若客户修改关键条款，是否要求重新提交业务、法务、财务或总经理复审？ | 🟡       |
