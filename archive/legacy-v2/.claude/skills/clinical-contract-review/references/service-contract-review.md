# 服务类合同审核要点（乙方视角—我方提供临床研究服务）

适用于：向客户提供CRO、SMO、数据管理、统计分析、医学、项目服务。

审核链路：起草人 → 业务Leader → 法务 → 财务（标准全流程）。

> 作为服务提供方，核心保护目标：限制服务范围、确保变更可收费、保护收款、避免无限责任、争取客户配合义务。

---

## 一、业务Leader重点审核维度（乙方视角）

### 1.1 服务范围与交付标准（保护边界）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 服务范围 | 服务范围是否清单化明确？是否删除"及其他"等模糊表述？ | 🔴 | 客户以模糊表述要求免费增项 |
| 交付标准 | 交付标准是否客观、可达？避免客户以主观标准拒收 | 🟡 | 客户以未约定的标准拒收 |
| 时间计划 | 时间表是否考虑了客户配合时间？客户不配合是否可顺延？ | 🟡 | 客户不配合导致延期，却追究我方 |
| 变更管理 | 客户变更是否有重新报价机制？我方是否有权拒绝不合理变更？ | 🔴 | 客户要求免费变更 |
| 排他性 | 是否禁止我方为其他客户服务？排他范围是否过于宽泛？ | ⚪ | 过度排他限制我方业务 |
| 分包限制 | 是否允许我方合理分包非核心工作？分包限制是否过于严格？ | 🔴 | 完全禁止分包，增加成本 |

### 1.2 人员与资源配置（保护我方自主权）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 关键人员 | 是否指定关键人员？是否保留替换权（提前通知即可）？ | 🔴 | 人员被锁定，无法调配 |
| 人员稳定性 | 人员被锁定时限是否合理？是否允许我方因业务需要调整？ | 🟡 | 人员被无限期锁定 |
| 人员资质 | 人员资质要求是否过高？是否超出实际工作需要？ | 🟡 | 资质要求过高，招聘成本大 |
| 资源投入 | FTE承诺是否过度？是否考虑了并行项目影响？ | 🟡 | FTE承诺过度，资源不足 |
| 驻地要求 | 驻地要求是否额外收费？差旅标准是否由我方制定？ | ⚪ | 驻地要求无偿 |

### 1.3 服务质量与监督（保护我方评估权）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| KPI/SLA | KPI是否客观、可达？是否考虑了客户配合因素（如入组率受客户招募能力影响）？ | 🟡 | 客户不配合导致KPI不达标 |
| 质量报告 | 报告频率是否过高？是否增加不必要的成本？ | ⚪ | 报告频率过高 |
| 稽查权利 | 客户稽查次数是否有限制？额外稽查是否收费？ | 🔴 | 客户频繁免费稽查 |
| 监管检查 | 监管检查是否由客户主导？我方配合义务是否限于合理范围？ | 🔴 | 我方承担监管检查主导责任 |
| 不合格处理 | CAPA时限是否合理？是否区分严重程度？ | 🟡 | 所有问题同等要求整改 |
| 质量报告 | 报告内容是否可控？是否暴露我方内部管理问题？ | ⚪ | 报告过度暴露内部问题 |

### 1.4 业务连续性（保护我方资源）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 业务连续性 | 业务连续性是否由客户配合？客户不配合是否免责？ | ⚪ | 客户不配合导致BCP失效 |
| 服务移交 | 客户更换服务商时，移交是否由客户付费？ | 🟡 | 客户要求免费移交 |
| 灾难恢复 | 灾难恢复是否由客户主导？我方仅配合？ | ⚪ | 我方承担全部灾难恢复 |

## 二、法务重点审核维度（乙方视角—限制责任、保护收款）

### 2.1 数据管理与知识产权（保护乙方）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 数据归属 | 客户数据归客户，但我方是否有权保留匿名化统计数据？ | 🟡 | 完全禁止我方使用数据 |
| 数据转移 | 数据转移是否由客户指定格式？格式不兼容时是否免责？ | 🔴 | 客户指定格式导致我方额外成本 |
| 知识产权 | 我方背景方法学、工具是否保留所有权？仅授予客户项目内使用权？ | 🟡 | 方法学被要求转让 |
| 前景IP | 项目改进的方法/工具是否归我方或共享？ | 🟡 | 改进成果全部归客户 |
| 保密义务 | 保密范围是否过宽？是否包含了我方通用知识？ | 🟡 | 保密范围过度扩大 |
| 数据访问权 | 合同终止后客户访问权是否需付费？ | 🟡 | 客户要求免费长期访问 |
| 数据删除 | 数据删除是否由客户指令？删除后是否免责？ | 🟡 | 删除后要求恢复 |

### 2.2 受试者保护与伦理合规（客户主导、我方配合）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 保险责任 | 受试者损害保险是否由客户（申办方）投保？我方仅承担过错责任？ | 🔴 | 我方承担非过错责任 |
| 伦理责任 | 伦理审查是否由客户负责？我方仅协助递交？ | 🟡 | 我方承担伦理审查责任 |
| 知情同意 | 知情同意翻译/修订是否由客户负责？费用由客户承担？ | ⚪ | 我方承担翻译费用 |
| AE/SAE报告 | AE/SAE报告流程是否在我方能力范围内？报告时限是否可达？ | 🔴 | 报告时限过短，不可达 |
| 数据隐私 | 隐私合规是否由客户（控制者）负责？我方仅按指令处理？ | 🔴 | 我方承担控制者责任 |
| 稽查配合 | 稽查配合是否额外收费？客户发起的额外稽查次数是否有限制？ | 🔴 | 频繁免费稽查 |
| 稽查衍生 | 稽查失败是否由客户原因（如数据造假、方案缺陷）导致？我方是否免责？ | 🔴 | 客户原因导致稽查失败却追究我方 |
| 受试者权益 | 受试者权益保护是否由客户承担？我方仅按GCP执行？ | 🔴 | 我方承担申办方责任 |

### 2.3 终止与退出（保护乙方已完成工作）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 单方终止 | 客户单方终止权是否受限？我方是否有对等终止权？ | 🟡 | 客户可随时终止 |
| 终止费用 | 客户终止时是否支付已完成工作费用？取消费用是否≥已完成工作X%？ | 🔴 | 客户终止不付款 |
| 工作移交 | 移交是否限于客户付费部分？未付费部分是否可保留？ | 🔴 | 客户要求移交全部，未付费 |
| 竞业限制 | 竞业限制是否过于宽泛？是否限制我方正常业务？ | ⚪ | 过度竞业限制 |
| 后续服务 | 终止后过渡期是否额外收费？ | 🟡 | 客户要求免费过渡期 |
| 资料交接 | 资料交接范围是否限于已付费部分？ | 🟡 | 客户要求全部交接 |
| 结算收尾 | 终止结算公式是否明确？客户是否必须支付已发生费用？ | 🟡 | 结算公式不明 |
| 系统权限回收 | 客户使用我方系统时，终止后是否回收权限？ | 🟡 | 客户继续免费使用 |

## 三、财务重点审核维度（乙方视角—确保收款）

### 3.1 费用与付款（服务类特殊关注）

| 检查项 | 审核要点（保护乙方收款） | 风险等级 | 常见风险 |
|--------|------------------------|---------|---------|
| 计费模式 | FTE/固定总价/里程碑/入组数哪种对我方最有利？是否有最低收费？ | 🟡 | 计费模式不利，收入不确定 |
| 差旅费用 | 差旅费是否由客户承担？或按我方标准实报实销？ | 🟡 | 差旅标准过低 |
| pass-through费用 | 中心实验室检测费、伦理审查费、受试者补偿是否由客户直接支付？ | 🟡 | 我方垫付大额费用 |
| 价格调整 | 长期合同是否有价格调整保护？ | ⚪ | 成本上涨无法调价 |
| 付款节点 | 付款是否与客观里程碑绑定？首付款是否≥30%？ | 🔴 | 付款节点不利 |
| 违约金 | 我方违约金是否过高？客户违约金是否过低？ | 🟡 | 违约金不对等 |
| 预算超支 | 客户超出预算时是否仍需支付已完成工作？ | 🟡 | 客户超支拒付 |
| 隐藏费用 | 是否有我方需承担但未列明的成本？ | 🔴 | 隐藏成本 |
| 费用拆分 | 人员费、管理费、差旅费、直接费用是否拆分？各项是否有最低收费？ | ⚪ | 客户要求分项免费 |
| 取消费用 | 项目取消时客户是否支付已完成工作费用？ | 🟡 | 客户取消不付款 |

### 3.2 付款绑定验收（保护乙方收款）

| 检查项 | 审核要点（保护乙方收款） | 风险等级 | 常见风险 |
|--------|------------------------|---------|---------|
| 验收绑定 | 付款是否过度绑定客户主观验收？是否争取"交付即验收"或"逾期自动通过"？ | 🔴 | 客户主观拖延验收 |
| 验收标准 | 验收标准是否客观、可量化（如query清理率≥95%）？ | 🔴 | 客户主观标准拒收 |
| 验收期 | 验收期是否≤5个工作日？逾期是否自动通过？ | ⚪ | 验收期过长 |
| 不合格处理 | 整改次数是否有上限？整改后是否仍需付款？ | 🟡 | 客户无限次整改 |
| 尾款/质保金 | 质保金是否≤5-10%？质保期是否≤12个月？ | 🟡 | 质保金过高、质保期过长 |
| 预付款比例 | 预付款是否≥30%？ | 🟡 | 预付款过低 |

## 四、服务类合同快速审核 Checklist（乙方视角—全岗位）

### 业务Leader必查
- [ ] 服务范围清单化，无"及其他"模糊表述
- [ ] 客户变更有重新报价机制，我方有权拒绝不合理变更
- [ ] 保留人员替换权（提前通知即可）
- [ ] 分包非核心工作不被禁止
- [ ] KPI客观、可达，考虑客户配合因素
- [ ] 客户稽查次数有限制，额外稽查收费
- [ ] 工期考虑了客户配合时间，不配合可顺延
- [ ] 客户承担必要配合义务（数据、场地、权限）
- [ ] 合同前后条款逻辑一致，客户承诺落纸
- [ ] 违约、责任场景有边界，排除不可控因素

### 法务必查
- [ ] 客户作为申办方承担GCP合规责任
- [ ] 客户作为控制者承担数据保护责任
- [ ] 受试者保险由客户投保，我方仅承担过错责任
- [ ] 稽查衍生风险由客户原因导致的免责
- [ ] 我方背景方法学/工具保留所有权
- [ ] 项目改进成果归我方或共享
- [ ] 赔偿上限合理（≤合同金额）
- [ ] 排除间接损失、利润损失、第三方索赔赔偿
- [ ] 客户终止时支付已完成工作费用
- [ ] 通用审核底线（5条）全部满足

### 财务必查
- [ ] 预付款≥30%
- [ ] 付款节点绑定客观里程碑，避免客户主观验收
- [ ] 验收逾期自动通过（≤5工作日）
- [ ] 质保金≤10%，质保期≤12个月
- [ ] 付款周期≤30天，逾期违约金≥日万分之五
- [ ] 客户逾期付款时我方有权暂停服务
- [ ] 差旅费由客户承担或按我方标准
- [ ] pass-through费用由客户直接支付
- [ ] 项目取消时客户支付已完成工作费用
- [ ] 争议款项不影响无争议部分付款
