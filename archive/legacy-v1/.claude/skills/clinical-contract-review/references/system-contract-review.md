# 系统类合同审核要点（乙方视角—我方提供系统/平台服务）

适用于：向客户提供EDC、DCT、CTMS、IWRS平台许可、开发、运维、升级服务。

审核链路：起草人 → 业务Leader → 法务 → 财务（标准全流程）。

> 作为系统服务提供方，核心保护目标：限制我方责任边界、确保收款权益、保护背景IP、控制交付成本、避免无限运维义务。

---

## 一、业务Leader重点审核维度（乙方视角）

### 1.1 部署与实施

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 部署模式 | 部署模式是否在我方技术能力范围内？本地部署是否成本过高？建议优先SaaS/私有云？ | 🟡 | 客户要求本地部署，成本超支 |
| 实施周期 | 实施周期是否考虑了客户配合时间（数据准备、接口对接）？客户延迟时是否可顺延？ | 🔴 | 客户拖延导致延期，却追究我方责任 |
| 验证责任 | CSV验证责任是否由客户承担？我方仅提供技术支持？避免承担全部验证成本？ | 🟡 | 客户要求我方承担全部验证 |
| 数据迁移 | 历史数据迁移是否属于额外收费服务？客户数据格式不兼容时是否免责？ | 🟡 | 客户要求免费迁移，成本超支 |
| 培训覆盖 | 培训人数、次数是否有限制？超出部分是否额外收费？ | ⚪ | 客户要求无限培训 |
| 系统对接 | 与第三方系统对接是否属于额外收费？第三方系统变更导致接口失效是否免责？ | 🟡 | 第三方系统变更导致我方接口失效 |

### 1.2 系统维护与技术支持（限制义务）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 维护范围 | 维护范围是否明确？是否包含版本升级、补丁、安全更新？非维护范围是否明确？ | 🟡 | 客户要求维护范围外服务 |
| 响应时间 | 响应时间SLA是否可达？是否区分严重度？非工作时间是否排除或额外收费？ | 🔴 | 7×24响应不可达 |
| 支持方式 | 支持方式是否明确？中文支持是否额外收费？ | 🟡 | 客户要求免费多语言支持 |
| 版本升级 | 是否保留我方版本升级控制权？升级窗口是否由我方安排？客户是否可拒绝合理升级？ | 🟡 | 客户拒绝升级导致系统问题 |
| 系统可用性 | 正常运行时间承诺（Uptime）是否在我方实际能力范围内？是否有"计划内维护"除外？ | 🔴 | 承诺过高，无法达标 |
| 扩容弹性 | 扩容是否属于额外收费？扩容价格是否提前锁定？ | 🟡 | 客户要求免费扩容 |

### 1.3 业务连续性（保护我方资源）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 灾难恢复 | 灾难恢复成本是否由客户分担？RTO/RPO承诺是否可达？ | 🟡 | 客户要求免费灾难恢复 |
| 业务连续性 | 业务连续性计划是否由客户配合实施？客户不配合是否免责？ | 🟡 | 客户不配合导致BCP失效 |
| 数据备份 | 备份是否属于标准服务？超出标准备份频率是否额外收费？ | 🟡 | 客户要求高频免费备份 |
| 服务移交 | 服务移交（客户更换服务商）时是否需支付移交费用？ | 🟡 | 客户要求免费移交 |

## 二、法务重点审核维度（乙方视角—限制责任、保护IP）

### 2.1 授权与许可条款（保护收益）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 许可范围 | 用户数/站点数/项目数是否明确？超出许可范围是否自动收费？ | 🔴 | 客户超量使用不付费 |
| 许可类型 | 订阅制 vs 永久许可？订阅制是否有利于我方持续收入？ | 🟡 | 永久许可导致后续无收入 |
| 授权地域 | 地域限制是否保护我方？全球授权是否价格足够高？ | 🟡 | 全球授权价格过低 |
| 授权期限 | 许可到期后是否需续费？是否有自动续费条款？ | 🟡 | 客户到期不续费却继续使用 |
| 许可转让 | 客户是否可随意转让许可？是否需我方同意？ | 🟡 | 客户转让许可给第三方 |
| 第三方接入 | 第三方接入是否需我方审批？是否额外收费？ | 🟡 | 客户未授权接入第三方 |
| 扩容计费 | 扩容是否自动按标准价格计费？是否有最低扩容量？ | 🟡 | 客户要求小额扩容免费 |

### 2.2 数据相关条款（限制责任）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 数据所有权 | 客户数据归客户所有，但我方是否有权保留匿名化统计数据？ | 🟡 | 完全禁止我方使用数据 |
| 数据导出 | 数据导出是否由客户自助完成？导出格式是否由客户指定？ | 🟡 | 客户要求我方承担导出格式转换 |
| 数据删除 | 数据删除是否由客户指令触发？删除后是否免责？ | 🟡 | 删除后客户要求恢复 |
| 数据安全 | 数据安全责任是否仅限于我方过错？非我方过错是否免责？ | 🔴 | 非我方过错导致安全问题却追究我方 |
| 审计追踪 | 审计追踪是否由我方系统提供？客户误操作是否免责？ | 🟡 | 客户误操作却追究系统问题 |
| 数据驻留 | 数据驻留是否由客户指定？驻留成本是否由客户承担？ | 🟡 | 客户指定高成本驻留 |
| 数据访问权 | 合同终止后客户数据访问权是否需付费？ | 🟡 | 客户要求免费长期访问 |
| 系统权限回收 | 客户终止后是否应立即回收我方系统权限？ | 🟡 | 客户继续使用却不付费 |

### 2.3 合规与监管要求（客户主导、我方配合）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| GxP合规 | GxP合规是否由客户负责（作为申办方）？我方仅提供技术支持？ | 🔴 | 我方承担申办方合规责任 |
| 数据保护 | 数据保护是否由客户（控制者）负责？我方（处理者）仅承担过错责任？ | 🔴 | 我方承担控制者责任 |
| 监管检查 | 监管检查是否由客户主导？我方配合义务是否限于合理范围？ | 🔴 | 我方承担监管检查主导责任 |
| 验证文档 | 验证文档是否由客户提供需求？超出标准文档是否额外收费？ | 🟡 | 客户要求免费定制验证文档 |
| 变更控制 | 系统变更是否由客户审批？变更实施是否由我方控制？ | 🟡 | 客户要求免费频繁变更 |
| 稽查衍生 | 稽查失败是否由客户原因导致？我方是否免责？ | 🔴 | 客户原因导致稽查失败却追究我方 |

### 2.4 知识产权（保护我方核心资产）

| 检查项 | 审核要点（保护乙方） | 风险等级 | 常见风险 |
|--------|---------------------|---------|---------|
| 背景IP | 我方背景IP（现有技术、平台）是否保留所有权？仅授予客户项目内使用权？ | 🔴 | 背景IP被要求转让 |
| 前景IP | 定制开发产生的知识产权是否归我方或共享？ | 🟡 | 定制成果全部归客户 |
| 知识产权保证 | 保证是否限于已知侵权？是否排除未知第三方专利？ | 🟡 | 保证过度宽泛 |
| 知识产权赔偿 | 赔偿是否上限？是否不超过合同金额？ | 🟡 | 赔偿无上限 |

## 三、财务重点审核维度（乙方视角—确保收款）

### 3.1 费用与付款（保护收款）

| 检查项 | 审核要点（保护乙方收款） | 风险等级 | 常见风险 |
|--------|------------------------|---------|---------|
| 费用结构 | 许可费、实施费、维护费、增值服务费是否拆分？各项是否有最低收费？ | 🟡 | 客户要求免费分项 |
| 扩容计费 | 扩容是否自动按标准价格计费？是否有扩容折扣下限？ | 🟡 | 客户要求大幅折扣 |
| 维护费涨幅 | 维护费涨幅是否有下限保护？是否可随成本上涨调整？ | 🟡 | 维护费被长期锁定 |
| 定制开发 | 定制开发是否额外收费？后续维护是否单独收费？ | 🟡 | 定制开发免费 |
| 隐藏费用 | 是否有我方需承担但未列明的成本？ | 🔴 | 隐藏成本导致亏损 |
| 付款节点 | 首付款是否≥30%？是否绑定可量化交付？ | 🔴 | 无预付款或付款节点不利 |
| 价格调整 | 长期合同是否有价格调整机制？是否有成本上涨保护？ | 🟡 | 价格被长期锁定 |
| 税费承担 | 税费是否由客户承担？或明确分担比例？ | ⚪ | 税费承担不明 |
| 发票类型 | 发票类型是否明确？是否影响我方税务？ | ⚪ | 发票类型不利 |
| 尾款/质保金 | 质保金是否≤5-10%？质保期是否≤12个月？ | 🟡 | 质保金过高、质保期过长 |

### 3.2 付款绑定验收（乙方收款保护）

| 检查项 | 审核要点（保护乙方收款） | 风险等级 | 常见风险 |
|--------|------------------------|---------|---------|
| 验收绑定 | 付款是否过度绑定客户主观验收？是否争取"交付即视为验收"或"逾期自动通过"？ | 🔴 | 客户主观拖延验收 |
| 验收标准 | 验收标准是否客观、可量化？ | 🔴 | 客户以主观标准拒收 |
| 验收期 | 验收期是否≤5个工作日？逾期是否自动通过？ | ⚪ | 验收期过长 |
| 不合格处理 | 不合格整改次数是否有上限？整改后是否仍需付款？ | 🟡 | 客户无限次整改要求 |

## 四、系统类合同快速审核 Checklist（乙方视角—全岗位）

### 业务Leader必查
- [ ] 部署模式在我方技术能力范围内
- [ ] 实施周期考虑了客户配合时间，客户延迟可顺延
- [ ] 系统可用性承诺在我方实际能力范围内
- [ ] 响应时间SLA可达，区分严重度
- [ ] 扩容属于额外收费，价格提前锁定
- [ ] 培训人数/次数有限制，超出额外收费
- [ ] 灾难恢复成本由客户分担或单独收费
- [ ] 第三方对接属于额外收费

### 法务必查
- [ ] 许可范围明确，超出自动收费
- [ ] 授权地域限制保护我方市场
- [ ] 数据安全责任仅限于我方过错
- [ ] 客户作为控制者承担数据保护合规责任
- [ ] 客户作为申办方承担GCP合规责任
- [ ] 稽查衍生风险由客户原因导致的免责
- [ ] 背景IP保留所有权，仅授予使用权
- [ ] 定制开发前景IP归我方或共享
- [ ] 赔偿上限合理（≤合同金额）
- [ ] 排除间接损失、利润损失赔偿
- [ ] 通用审核底线（5条）全部满足

### 财务必查
- [ ] 预付款≥30%
- [ ] 付款节点绑定客观交付，避免客户主观验收
- [ ] 验收逾期自动通过（≤5工作日）
- [ ] 质保金≤10%，质保期≤12个月
- [ ] 付款周期≤30天，逾期违约金≥日万分之五
- [ ] 客户逾期付款时我方有权暂停服务
- [ ] 费用结构清晰，无隐藏成本
- [ ] 年度维护费有涨幅保护
- [ ] 扩容有标准价格，不随意折扣
- [ ] 争议款项不影响无争议部分付款
